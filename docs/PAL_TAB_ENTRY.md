# Pal 底部入口

2026-10-26，当前本地源码 3.2.0-rc.3。用户要求在原四个底部入口新增Pal，方便进入家园。

## 行为

底部依次为 **日记 / 校园 / 时光 / Pal / 我的**。点击Pal直接打开现有全屏家园 `/pages/companion/index`，个人页原入口、好友共享路径及当前小屋内容保留。

Pal使用主包轻量页面 `pages/pal/index`，原生导航仍由微信管理；家园及大图继续保留在普通分包。只新增两张81×81的原创线条图标，与旧图标同组生成；旧8张图标与本轮基线逐字节一致。

从家园返回后，Pal页展示伙伴卡和“进入家园”按钮，用户可重新进入或切换其他Tab。返回本身不会自动把用户弹回家园。加载失败显示友好提示，点击按钮重试；重复点击不会叠加跳转，隐藏/卸载后的旧回调不会覆盖页面。
