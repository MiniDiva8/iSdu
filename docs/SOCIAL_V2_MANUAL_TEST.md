# iSdu Social V2 双账号与真机验收清单

更新日期：2026-08-15

本清单必须由账号 A（iOS）与账号 B（Android）在真实 CloudBase 测试环境执行。不要在文档中填写 OpenID、微信号、手机号、环境 ID或任何密钥；只记录匿名编号、时间、结果和 requestId。

## 1. 测试前条件

- [ ] 已按 `CLOUDBASE_SECURITY_DEPLOYMENT.md` 创建 8 个集合、索引和安全规则。
- [ ] 三个云函数均已重新部署，版本与当前 Git SHA 一致。
- [ ] A、B 均为体验成员，使用不同微信账号。
- [ ] 一台 iOS 与一台 Android 均已更新到比赛要求支持的微信版本。
- [ ] A 准备一条纯文字、一条单图、一条三图本机回忆；照片不含真实敏感信息。
- [ ] 已保留比赛第一版标签/提交，可独立恢复。

## 2. 可信身份与本地兼容

- [ ] 未开启云功能时，A、B 都能继续读写本机数据，启动不依赖网络。
- [ ] A、B 主动开启云功能后获得不同的随机 `usr_` iSdu ID。
- [ ] 返回数据和控制台日志不包含 OpenID、APPID、identityHash 或照片地址。
- [ ] 客户端直接读取 `users`、`memories` 等集合被拒绝。
- [ ] 修改客户端 payload 中伪造的 userId/ownerUserId 不会改变真实调用者。

## 3. 本机回忆迁移

- [ ] A 迁移前看到“默认全部私密”和“本机副本保留”的说明。
- [ ] 纯文字、单图、三图回忆全部回读一致：正文、坐标、图片数、记录时间正确。
- [ ] 重复执行不会产生重复回忆或重复图片引用。
- [ ] 人为制造一张丢失图片后，该条明确失败且仍保持本地模式，可修复后重试。
- [ ] 迁移成功后重启，云端为主数据；CloudBase 故障时明确报错，不偷偷写回本地。

## 4. 好友邀请

- [ ] A 生成分享卡片，B 打开后只看到 A 的最小资料。
- [ ] B 必须点击“接受邀请”才成为好友。
- [ ] 同一卡片重复接受不产生第二条关系。
- [ ] A 自己打开自己的邀请被拒绝。
- [ ] 使用超过 24 小时的邀请被拒绝。
- [ ] A、B 好友列表都只出现一条对应关系。

## 5. 三种回忆权限

- [ ] `private`：B 的详情、图片、点赞和好友地图点全部不可访问。
- [ ] `selected_friends` 选择 B：B 可访问；未选择任何好友时客户端和服务端均拒绝保存。
- [ ] `friends`：B 可访问。
- [ ] A 将可见范围改回私密，B 刷新后详情、图片、点赞和地图点立即失效。
- [ ] A 删除 B 后，B 立即失去全部好友访问权。
- [ ] A 与 B 重新建立好友关系，旧的“部分好友”授权不会自动恢复。

## 6. 点赞

- [ ] B 点赞一次，计数增加 1；B 取消后减少 1。
- [ ] 快速连续点击或重复请求不会产生重复点赞。
- [ ] A 查看自己的回忆时不显示点赞按钮。
- [ ] 非好友、私密回忆、未被选中的好友均不能点赞。
- [ ] 删除好友会清理双方仍有效的点赞并修正计数。
- [ ] 客户端只收到 `likeCount` 与 `likedByMe`，收不到点赞用户列表。

## 7. 好友 24 小时地图

- [ ] 默认图层仍为“我的回忆”，主动切换后才显示“好友 24h”。
- [ ] 只显示服务端首次共享时间 24 小时内、仍有权限、坐标合法且地图版本兼容的圆点。
- [ ] 好友圆点小于个人标记，列表加载时不直接请求照片。
- [ ] 点击圆点先鉴权显示卡片，进入详情再次鉴权。
- [ ] 超过 24 小时、改私密、删除好友或地图版本不兼容后，刷新即消失。
- [ ] 造出超过 50 条测试点时可以分页继续读取且不重复第一页。

## 8. 图片访问与弱网

- [ ] B 不能通过 fileID 或旧客户端请求直接读取无权限图片。
- [ ] 授权后临时图片地址可以显示，但没有写入数据库或长期 Storage。
- [ ] A 撤销权限后新请求被拒绝；已下载到 B 设备缓存的副本无法远程抹除，此限制已在隐私说明中告知。
- [ ] 上传中断、云函数超时、临时地址失效时页面不白屏且可以重试。
- [ ] iOS 与 Android 分别验证 1—3 张图、前后台切换、冷启动和弱网恢复。

## 9. 云端数据删除

- [ ] 未进行二次确认时不会删除。
- [ ] A 删除云端账号后，A 的云回忆、图片、点赞、好友关系、邀请和资料无法再读取。
- [ ] A 的本机备份仍保留，并已切回本地模式。
- [ ] 若提示遗留云文件数量，记录 requestId 并由运营者在控制台完成清理。
