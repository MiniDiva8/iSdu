## 用户体验

- Pal本人小屋的工具栏点击“聊天”；首次明确同意向OpenAI发送聊天文字、伙伴名字及最近两轮对话。每天最多3次，输入160字以内，短回复。
- 普通“摸摸头”、走动、签到、任务、家具、模板来信继续使用原有逻辑，不调用AI，不受额度暂停影响。
- 信箱的“AI来信”中点击“读最新日记，写封短信”，先看到本人最新云端文字日记的片段，并逐次确认发送前600字和心情；不发送照片、坐标或好友日记。每周最多2封；同一篇同片段直接返回已保存的信。客户端提交实际确认的文字片段和心情，服务端重新读取本人日记并核对；预览后日记被编辑会拒绝发送，要求重新确认。
- AI信与日常模板信分开。保留最近12封，可逐封删除；聊天页可“停用并清空AI记录”，原日记和小屋不受影响。现有账号删除直接移除users文档，同时移除私有AI正文。
- 额度按北京时间自然日、周一开始的自然周、自然月计算。预算耗尽显示暂停提示，下月自动使用新月账本；已经保存的信仍能阅读。

## 30元预算如何限制

预算由云函数和数据库事务控制，客户端不能设置模型、价格、预算、身份或历史。每次生成先原子预留输入4096 token与输出192（聊天）/384（来信）的最高记账费用，再核对完整输入的真实token数量。并发请求共用一个月度账本，不会各自独立“看起来还有余额”。

记账固定使用保守预算折算10元/USD、输入$0.125/百万（覆盖30分钟缓存写入价）及输出$0.50/百万。30元预算约对应最多$3的模型费用，留有兑换/计价余量。这是内部预算折算，不是实时汇率；与前期按7.2元估算的预期账单金额不同。云开发/存储费用不包含在模型预算里。

正常结果按usage结算并释放差额；未知网络结果或没有可信用量时保留单次最高额，不猜测退款，不自动重试。客户端保留未知结果的requestId，使用独立result接口只查询原结果；该查询在额度用尽或服务暂停后仍可使用，不再生成。明确失败后，下一次用户操作使用新ID，仍受次数和预算限制。已发送的调用在停用后仍可能产生费用，但结果不会重新写回清空后的记录。跨月回包记回原预留月，不挤占下一月。

个人限额和预算审计在清空AI正文后保留，防止清空后绕过上限。出现异常超出用量边界时，本月全站AI自动暂停，供运维检查；不要手动删除月账本来“恢复额度”。

## 云端操作说明

1. 使用当前源码的 cloudfunctions/pal-ai 创建独立云函数，部署以下运行文件：index.js、package.json、config.json、lib/policy.js、lib/openai-client.js、lib/cloud-store.js、lib/handler.js。测试文件不用上传。Node运行环境与wx-server-sdk 4.0.2保持兼容；安装该函数依赖，超时配置60秒。本次官方微信创建的实际运行时是Nodejs16.13（v16.13.1），内存256MB；不能把配置中的Nodejs20.19建议值当作已生效。
2. 新增 pal_ai_budgets、pal_ai_requests 两个集合，规则均为ADMINONLY（拒绝客户端直接读写）。使用文档ID事务，不需要为本功能开放公共读写。保留现有users、memories及其原规则。
3. 声明 security.msgSecCheck 权限，沿用可信微信身份。真实微信内容安全调用未验证时不能称为已开通。
4. 在该函数的云端环境变量中安全填写 OPENAI_API_KEY；不要发在聊天里、写入仓库或前端配置。使用独立项目的受限Key较容易核对账单。
5. PAL_AI_ENABLED 初始设为 false。确认部署环境对官方 api.openai.com:443 的访问条件、API账号的模型可用性、内容检查以及集合规则后，再改为 true。不改用未核实的中转服务。
6. 在真实微信登录状态，主动开启AI，用不含个人信息的一句话验证。检查返回usage、月账本结算、个人次数；再用本人同意的测试日记验证来信、读取与删除。真实接通前不要替用户发送真实日记。
7. 客户端需另行授权上传/预览并在设备上验收。当前聊天和来信源文件的存在不代表旧体验包已经包含它们。

未配置Key/开关关闭/函数未部署时，用户只会看到未开通提示；普通Pal互动仍可用。关闭开关仅阻止新请求，已进入发送阶段的请求按原预算结算。

## 数据与维护

users.palAI只保存当前账号的同意代次、两轮聊天、12封信、有限重试结果及在途锁。pal_ai_budgets只存月度合计，pal_ai_requests只存哈希键、状态、计数和费用，不存日记或聊天正文。对外接口明确挑选字段，不返回users原文、OpenID或密钥；错误不返回上游原始内容。

不要修改已部署的auth/friend/memory/companion函数来开通本功能。现有账号删除时users文档必须保持最终删除，这已经同时覆盖AI正文；预算审计记录不应随之删除或重置。

新增测试入口：npm run test:pal-ai；完整检查：npm run check。证据目录：.verification/pal-ai-20261029。最后的verification-summary.json区分离线测试、浏览器、官方离线编译和未运行的真实API/真机检查。
