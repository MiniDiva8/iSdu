# 首页背景与记录入口优化

2026-10-28，承接已上传的3.2.0rc.6。用户要求完成后更新体验版；本次仍仅发布客户端，不部署云函数或提交正式审核。

## 记录回忆

- 第四个工具按钮为“主题”，直接打开原主题转盘，不必先展开更多选项。
- 云端模式的“谁可以看这篇日记”位于地点名称与提示的正下方，三档范围同排显示；部分好友的名单、空态和加载错误保留。
- 主题摘要与自定义主题仍可编辑；保存、草稿、默认私有和服务端权限规则保持。
- 本机模式继续仅存本机，不通过界面布局变化自动开启云端或共享。

## 日记首页背景

- 日记首页的“背景”入口可以从相册选图、替换、调整背景清晰度或恢复默认。
- 图片单独保存在本机管理目录，不上传云端，不成为日记照片，不改变照片数量和任务事实。
- 图片仅作为装饰层，不能截获点击；日历、标题、操作区保留纸色保护，设置弹层保持独立清楚，不调整前景整体透明度。
- 选择限制为一张不超过10MB的可读取图片。选择取消、保存失败、坏图与相册生命周期均保留重试或默认底色；不删除旧日记数据。
- 清除全部本机数据时一并清除首页背景，并如实显示部分清理失败。

## 验证与发布

完整测试、类型、lint、格式、安全检查以及本轮实际模板与官方离线编译结果，以`integration-rc7-20261028/evidence`中匹配本次冻结代码的记录为准。浏览器模拟不代替微信运行或真机验收。

用户附图只用于理解布局要求，没有复制进工程、背景预设或交付包。此功能不修改时光封面、校园地图或伙伴小屋背景。
