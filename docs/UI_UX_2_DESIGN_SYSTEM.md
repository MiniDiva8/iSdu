# iSdu UI / UX 2.0 设计系统 ## 设计定位 当前界面采用 **Warm Editorial

Campus**：温暖校园、编辑排版、私人记忆册与现代地图产品的结合。地图、照片和文字是主角，组件与装饰应后退一级。

## 不可变边界 - 不修改 `Memory` 数据模型、Repository、本地图片持久化和 Storage 键名。 -

不修改地图图片、地图版本、比例坐标、有效区域或新旧地图兼容逻辑。 -
不改变现有创建、编辑、删除、筛选、搜索和页面跳转结果。 - UI
中隐藏技术坐标，但数据仍按原有比例坐标保存。 ## Design Token 全局 Token 定义在
`miniprogram/app.wxss`，页面不得自行创造近似值。 - Background：`#F6F2EA` - Surface：`#FFFDF9` -
Secondary Surface：`#F1ECE3` - Primary：`#437A64` - Primary Pressed：`#386B56` - Primary
Soft：`#E6F0EA` - Text Primary：`#222620` - Text Secondary：`#6D726B` - Danger：`#C65A55` -
Spacing：4、8、12、16、20、24、32、40px - Radius：12、16、20px 与 Pill - Shadow：只允许悬浮控件和
Bottom Sheet 使用轻阴影 ## 页面结构 - 地图：首页主舞台；筛选和数量为统一悬浮控件；Marker
使用小点；点击后打开 Bottom Sheet。 - 记录：点击 Tab 直接进入地图选点；首次仅显示一次轻量引导。 -
时光：整张回忆条目可点击，保留轻量“在地图中查看”；搜索框和月份标题降噪。 -
编辑：地点、照片、文字、心情、分类按内容顺序排列，移除重复卡片。 -
详情：按地点、时间、照片、故事、标签和地图位置阅读，隐藏百分比技术坐标。 ## 响应式规则 -
普通内容最大宽度 720px，地图最大宽度 960px，居中显示。 - 正文字号使用 px，不随 iPad 宽度按比例放大。

- 页面左右间距默认 20px，340px 及以下使用 16px。 - 底部固定区域与页面均包含
  `safe-area-inset-bottom`。 - 目标人工测试宽度：320、375、390、430、768px。 ## 回归检查
  每次页面修改后检查：单一视觉焦点、灰度信息层级、3 秒内可理解下一步、点击区域不小于
  44px、无横向滚动、地图坐标测试全部通过。
