# 小屋顶部胶囊遮挡修复

2026-10-27，本地源码仍为 **3.2.0-rc.4**。本次修改尚未上传体验版；2026-10-26 的冻结体验包不包含此修复。

## 问题与修复

用户提供的手机截图中，小屋右上角设置齿轮落在微信原生菜单胶囊下方，无法点击。原来的 `companionTopInset()` 只返回状态栏高度，没有为胶囊所在的导航区域预留空间。

现在共享顶距优先读取 `wx.getMenuButtonBoundingClientRect()`，让自定义顶栏从胶囊底部再向下留出 8px；同时至少保留状态栏下方 44px 的导航区域。接口缺失、抛错或返回无效矩形时使用该保底间距。小屋、任务、仓库、信箱、伙伴资料卡、合影六个页面共同使用此顶距，首页钱包与工具栏继续随顶距定位。

小屋齿轮增加了“伙伴改名与场景设置”的无障碍说明。操作路径仍为 **Pal → 小屋齿轮 → 伙伴资料卡 → 我们的小设定 → 保存伙伴资料**。本次不修改伙伴存档、余额、角色、主题及家具数据。
