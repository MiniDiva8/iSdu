# 校园伙伴小屋框架

本轮按用户追加要求完成框架，正式宠物、装饰及家具形象等待另一边的设计素材。
当前源码版本为 3.2.0-rc.1；现有已发布体验版为 3.1.0rc.3。
本轮没有上传新体验版，没有部署新增云函数。

## 可运行范围

- 日记首页、「我的」新增小屋入口；好友列表新增「去小屋」入口。
- 小院支持领取伙伴、可跳过引导、点击行走、互动、拖动画面、缩放及居中。
- 家具支持库存兑换、摆放、拖动、旋转、收回；画布失败可使用家具列表并重试画布。
- 签到、近六天补签、任务奖励、免费光点抽取、重复形象转换、换装与资料偏好。
- 伙伴来信、已读状态、好友留言接口；两类内容单独显示。
- 完整小院卡片生成、用户主动保存相册及分享入口。
- 静态图片与精灵图均通过配置适配；没有硬编码最终宠物图像。
- 原四个 Tab、日记日历、草稿、相册、个人页、心情/主题转盘和记忆瓶保留。

预览用目录、颜色、名称和奖励数值均为配置，正式设计接入时可以调整。
它们不代表最终美术和养成数值定稿。

## 保存与隐私

养成状态保存在独立本机键 isdu:companion:v1，不改写原日记结构。
失败写入不更新存档，损坏存档提示恢复/确认重置，不静默覆盖。
本机清除包括伙伴和库存；另行保留的云端清理标记用于找到先前写入的家园数据，
不会因重置本机小屋而遗忘清理云端来访的责任。

主动展示的小屋只含名字、外观和布局，默认仅自己可见。
新 companion-api 验证可信身份和当前双方好友关系，拒绝陌生人和已撤销关系。
留言内容安全检查失败时不写入；访客写入前记录清理标记，网络回包丢失也能后续清理。
关闭来访和删除云端小屋均是独立可执行操作，不依赖本机是否仍持有宠物存档。
