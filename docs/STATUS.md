## 已完成：Memory 与本地 Repository

- 集中定义 `Memory`、`CreateMemoryInput`、`UpdateMemoryInput`、心情、分类和来源类型。
- Memory 包含：`id`、`text`、`imagePaths`、`placeName`、`mood`、`category`、`mapXRatio`、`mapYRatio`、`recordedAt`、`origin`、`createdAt`、`updatedAt`。
- 正文最多 2000 字、地点最多 60 字、照片最多 3 张；照片或非空正文至少存在一项。
- 日期统一保存为标准 ISO 字符串并按 `recordedAt` 倒序读取。
- 页面不直接散落调用 `wx.setStorageSync`；Storage 细节由 `LocalMemoryRepository` 封装。
- Storage key：`sdu-memory:memories:v1`，快照 `schemaVersion=1`。
- Repository 支持 list/get/create/update/delete、重复 ID 防护、非法 ID、记录不存在、读写失败、损坏 JSON 和未知 schema 错误。
- Demo Memory 使用 `origin=demo`，用户创建使用 `origin=user`。
- Demo 只在 Storage key 从未存在时 Seed；用户把数据删除到空数组后不会再次自动灌入。

## 已完成：照片持久化

- 使用 `wx.chooseMedia` 选择相册或相机图片，请求压缩结果，页面限制总数为 1—3 张并拒绝压缩后超过 5 MiB 的单张图片。
- 临时图片不会直接写入 Memory。
- 图片通过 FileSystemManager 保存到：

  ```text
  USER_DATA_PATH/sdu-memory/images/<memoryId>/
  ```

- 新建时先保存全部新图，再写 Repository；任一图片失败会回滚本轮已保存文件。
- Repository 写入失败时清理本轮新增图片，不创建引用无效路径的日记。
- 编辑时先保存新图，成功更新 Repository 后才清理被移除且不再被其他日记引用的旧图。
- 删除时先删除 Repository 数据，再查询剩余引用，只清理不再被引用的受管文件。
- 图片服务拒绝清理受管目录外路径和父目录穿越路径。
- 图片丢失会在地图、编辑或详情中降级并给出提示，不导致白屏。

## 已知限制

- 当前没有星点聚合；日记多时标记可能重叠。
- 星点会随地图一起缩放，尚未实现屏幕尺寸恒定的苹果照片地图式标记。
- 本地照片暂未做统一压缩、总容量统计或孤儿文件后台巡检。
- 清除小程序数据或卸载小程序会删除本地 Storage 和用户文件。
- 当前地图包含较大边界外留白；正式裁切或换图前必须迁移历史比例坐标。
- 不支持从编辑页重新选择位置；如需改变地点，可新建一条回忆。
