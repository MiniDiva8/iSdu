# 伙伴游乐场：参考画面纠偏

2026-10-29，根据用户“与参考网站差太远，请修改优化”的反馈完成本地修正。基于当前 3.2.0-rc.8 真实工作树，未用旧版本覆盖新版内容；本轮未上传或部署。

## 这次实际改变了什么

上一版把任务页样式放进了游乐场：大标题、说明、钱包、圆角舞台、下方任务卡和常驻名单挤占画面。参考站则以满屏草地和角色为主体，短纸条就在点击的角色身上翻出。

本次改为：

- 草地和 Canvas 填满可用视口，没有滚动内容区；移除常驻标题、钱包、装饰章、舞台边框和人物名字标签。
- 20 个独立、大小与位置各异的角色实例，来自现有八种校园伙伴；变体使用本工程绘制的小装饰。每个实例独立跳跃、移动、碰撞和投影。
- 点击时角色本体经过 460ms 前后翻面；约 154×160px 的短纸条在角色原处出现，边缘自动避让。纸条使用真正的 WXML keyed 实例，连续翻不同角色也会重新播放。
- 全屏 85 片彩纸、右下角重玩按钮与纸条内可取消的五秒任务引导。暂停、名单与任务入口收进左下角菜单。
- 旋转屏幕后按新舞台重新摆正纸条；Canvas 失败时名单仍可打开纸条，降级提示不会挡住按钮。导航失败时关闭菜单并显示可重试提示。

角色图片仍使用本项目素材，与参考站角色造型不同；未引入参考站的 JavaScript、SVG 或品牌资源。

## 任务与存档

20 个场上实例映射到原有八类角色和九项任务；实例 ID 与任务 ID 分开。找到幸运实例只登记原 interact 事件，领奖仍走原 claim 和事实核验；不会产生 20 份可重复领取的角色奖励。

日记、照片、布置、读信、真实好友来访和三天记录条件保持。旧余额、家具、角色所有权、存档版本、云服务契约和发布记录不由本轮改变。后台计时器、晚到回调、跨日回读和导航栈复用继续有回归覆盖。
