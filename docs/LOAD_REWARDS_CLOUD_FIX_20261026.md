首页提前显示日期不代表已读到记录。首次读取完成前日期暂不可点，写新日记的加号仍可用。后台刷新时保留上次内容；失败明确提示，不能把旧缓存当作本次刷新成功。

仅缓存当前会话的本人日记，不落盘。创建、修改、删除、清空、云模式/激活状态变化会失效。好友小屋与好友内容不使用此缓存，每次由云端验权。

## 一键领取

只领取已完成且未领取的日常与一次性任务，原金额、任务条件、签到、补签与单项领取保留。没有可领任务时按钮禁用。

一次批量命令读取一次日记事实，整体保存一次状态；写失败不留下部分奖励，重复点击与并发不重复发奖。跨北京时间零点会要求刷新再领。成功后余额、按钮与完成数量一起刷新。

## 图六意味着什么

仅从通用提示只能判断调用失败，不能判断好友有没有使用或开放小屋。匹配体验版的 release-evidence.json 和 COMPANION_CLOUD_SETUP.md 则明确记载：本机伙伴功能已交付，companion-api 未部署。因此目前首先需要完成开发者侧的伙伴云部署。

普通用户反复点击“重新读取”无法开通未部署服务。部署后，主人还需要主动开放小屋；领取伙伴不会自动向好友开放，也不会上传日记。HOME_UNAVAILABLE 统一涵盖未开放、未发布、非好友或关系撤销，客户端不进一步猜测好友私密状态。

## 你需要做什么

不需要购买独立服务器或重新准备美术素材。下一步需授权在当前小程序对应的 CloudBase 环境执行以下操作；本轮未执行外部部署、上传。

1. **部署服务。** 更新现有 memory-api，让本人回忆图片批量签发在云端生效；首次部署 cloudfunctions/companion-api，安装其 package.json 对应服务端依赖。只上传客户端不会同步更新云函数。
2. **创建集合与规则。** 建立 companion_homes、companion_visits，客户端安全规则均为 read:false、write:false，仅由云函数管理员 SDK 访问。沿用现有 users 和 friendships 规则。
3. **核对索引。** companion_visits 配置 ownerUserId ASC + _id ASC 组合索引及 visitorUserId ASC 普通索引；按实际查询与环境提示核对。
4. **配置内容安全。** 保留 companion-api/config.json 声明的 security.msgSecCheck，确认云调用权限可用；审核服务故障时禁止跳过检测。
5. **双账号验证。** 双方建立现有 iSdu 双向好友。主人到 Pal 小屋右上角“资料卡 → 好友来做客”，点击“主动开放给现有好友”；布置改变后点击“同步当前本机布置”。确认真实访问、留言，并验证关闭来访或删好友后即时失权。
6. **更新体验版。** 上传包含本轮修改的客户端，手机才能看到加载优化和一键领取。建议用新候选号区分原 rc.3 冻结包；本轮未升号或改写发布记录。

若平台需要登录、扫码或账号授权，届时由你完成账号动作。其余配置可依据本工程实施。完整协议、索引、安全规则与清除语义见 [COMPANION_CLOUD_SETUP.md](COMPANION_CLOUD_SETUP.md)。

## 验证与证据

日志在 .verification/load-rewards-20261026。最终统计以 verification-summary.json 与 full-check.log 为准，不沿用旧上传测试数字。

本地对比使用同样 12 条模拟本人回忆、每条 1 张图、每次签发注入 40ms 延迟：旧实现签发 12 次，新实现 1 次，本次约 570ms 对 47ms。同一会话连续三次读取只调用一次数据源。**这是本地机制对比，不是手机或真实云端耗时承诺。**

浏览器适配器检查当前 WXML/WXSS 的 320、390、430 像素宽度，共 33 个状态布局，覆盖初始日历、保留内容、领取前后及云错误。浏览器模拟不等同微信原生或手机验收。真实首次云端耗时、内容安全权限、事务行为、双账号及 iOS/Android 手机验收尚未执行。

图片每批最多签发 50 个文件，依据 [CloudBase 临时链接文档](https://intl.cloud.tencent.com/zh/document/product/1266/71666?lang=zh)。函数资源缺失与运行失败分别处理，参照 [CloudBase 云函数错误码](https://docs.cloudbase.net/http-api/functions/%E4%BA%91%E5%87%BD%E6%95%B0)；SDK 与 HTTP 形态不同，代码仅在明确资源缺失时判为未部署。
