# 风险登记册

更新日期：2026-07-30

等级说明：

- 严重程度：低 / 中 / 高 / 致命。
- 发生概率：低 / 中 / 高。
- “致命”表示可能造成隐私泄露、比赛无法提交、核心闭环不可演示或原创性/许可不合格。

| ID | 风险 | 严重程度 | 概率 | 预防方案 | 发生后的处理方案 |
|---|---|---|---|---|---|
| R-01 | 第三方项目过时 | 高 | 高 | 不以旧日记项目为底座；核实最近提交、旧 API 和工具配置；核心自行实现 | 停止迁移，隔离受影响代码；换成微信官方当前 API 并补回归测试 |
| R-02 | 微信 API / 基础库兼容问题 | 高 | 中 | 以官方 Demo/文档为准；固定基础库与 WebView 渲染；每个复杂组件真机验证 | 降低到已验证 API 组合；替换单个组件，不整体换框架；记录兼容矩阵 |
| R-03 | 小程序包体超限或首包过大 | 高 | 中 | TDesign 按页面注册；不混用 UI；每次集成记录构建包体；压缩图片和地图 | 删除未使用组件/资源；延后非 P0；必要时在 P0 稳定后再做分包 |
| R-04 | 地图缩放后标记漂移 | 致命 | 中 | 地图和标记同一变换容器；持久化比例坐标；纯函数测试多视口/缩放/平移 | 暂停业务叠加，回到地图技术样片；修正坐标模型并迁移已有本地数据 |
| R-05 | 图片选择、持久化或上传失败 | 高 | 高 | 限制 1 至 3 张；校验类型/大小；本地保存草稿；云上传可重试；保存 `fileID` | 保留未上传草稿和失败状态；允许单图重试/移除；不因部分失败丢失正文 |
| R-06 | CloudBase 权限配置错误 | 致命 | 中 | 集合和存储仅创建者可读写；环境 ID 显式；双用户越权反向测试作为发布门禁 | 立即停止演示/发布并收紧规则；审计日志和受影响数据；轮换暴露链接/配置 |
| R-07 | 私人日记或照片泄露 | 致命 | 中 | 不做公开查询；日志脱敏；存储私有；不保存长期公开 URL；最小权限 | 下线相关入口；撤销公共权限和链接；删除缓存；通知用户并复盘数据范围 |
| R-08 | 第三方许可证不清或元数据冲突 | 致命 | 中 | 无明确 LICENSE 不复制；逐文件记录来源；第三方声明随引入更新 | 删除无法证明许可的内容并重写；联系作者或更换方案；更新比赛披露 |
| R-09 | 复制过多无关代码 | 高 | 中 | 从空骨架自建；每个新增文件映射到 P0；禁止整仓迁移；评审超范围关键词 | 回退独立迁移提交；提取真正需要的最小接口并原创重写 |
| R-10 | 25 天工期不足 | 致命 | 高 | 严格 P0 → P1；一个里程碑一轮；每天保持可演示版本；本地 Demo 保底 | 冻结 P1、动效和非关键美化；优先真机闭环、Demo 脚本和修复 |
| R-11 | 视觉风格不统一 | 中 | 中 | 单一 TDesign；设计 token；统一照片卡片/状态页/标记；不复制商城主题 | 做集中视觉审查；先统一色彩、字体、间距、圆角，再修个别页面 |
| R-12 | TDesign Skyline 兼容不完整 | 高 | 高（若启用） | 比赛版固定 WebView；不启用 Skyline；复杂组件逐个真机验证 | 回退 WebView；禁止为 Skyline 大规模改造 P0 |
| R-13 | TDesign 自身出现阻断缺陷 | 高 | 低至中 | 精确锁版本；下一里程碑只做最小组件冒烟；保留原生组件降级路径 | 优先用原生组件替代单个阻断组件；只有系统性阻断才重新评估 Vant |
| R-14 | TypeScript / 开发者工具编译链不一致 | 高 | 中 | 最小骨架先验证；命令行类型检查 + 开发者工具编译；配置保持单一 | 修复配置并固定工具版本；不能用 `any` 或整仓改 JS 掩盖问题 |
| R-15 | 本地 Demo 数据损坏或版本升级丢失 | 高 | 中 | 版本化 key、schema 校验、原子快照、显式 Seed/重置、迁移测试 | 进入可恢复空/错误状态；保留原值备份；提供一次性迁移/重置选项 |
| R-16 | 临时图片路径重启后失效 | 高 | 高 | 本地模式把选择结果持久化为小程序本地文件；Seed 用仓库内合规资产 | 标记图片失败并允许重选；不删除正文/坐标；修复路径后补迁移 |
| R-17 | 云端与本地数据实现行为不一致 | 高 | 中 | 统一 Repository 契约和契约测试；页面不直接调用存储 API | 以契约测试定位差异；切回本地 Demo 保证比赛演示；修复云实现 |
| R-18 | 真实 AppID、环境 ID、OpenID 或令牌误提交 | 致命 | 中 | 私有配置忽略；提交前敏感扫描；示例只用占位符；不在日志输出 | 立即撤销/轮换凭据；从待提交内容移除；必要时按安全流程清理历史 |
| R-19 | CloudBase Skills/MCP 引入过大权限 | 高 | 中 | 当前不安装；后续固定版本、项目级安装、MCP 单独审批、显式环境 ID | 禁用/卸载连接；撤销令牌和权限；检查是否产生资源变更 |
| R-20 | 模拟器正常但真机失败 | 致命 | 中 | 每个关键流程真机检查；至少一台比赛演示机；记录微信/系统版本 | 冻结新功能，优先修演示机；准备稳定本地 Demo 数据和离线演示路径 |
| R-21 | 正式校园地图素材版权或体积不合格 | 高 | 中 | 使用原创地图；保留创作源文件和授权证据；导出前做尺寸/压缩预算 | 替换为原创简化版；删除来源不清素材；重新导出多分辨率资源 |
| R-22 | Demo 视频在五分钟内无法讲清闭环 | 高 | 中 | 尽早写演示脚本；Seed 数据覆盖地图、详情、时间轴、回放；每周彩排 | 删除非核心镜头；固定 3 至 4 条代表记忆；突出“空间 + 时间”差异 |

## 当前最高优先级

1. R-10：25 天工期。
2. R-04：地图标记漂移。
3. R-06 / R-07：CloudBase 权限和隐私。
4. R-20：真机可运行。
5. R-08：许可证与原创性。

每个里程碑结束时更新本表的概率、状态和新证据；风险未关闭不等于里程碑一定阻断，但“致命”风险必须有明确发布门禁。
