# 日记版记忆瓶合并

本次以 EMMO 日记版为基线，保留日记首页、心情日历、文字草稿、照片墙、位置选择、
新版个人页、偏好设置和心情/主题转盘，并合入独立记忆瓶。
「日记/校园/时光/我的」四个 Tab 保留，扫码入口仍使用日记首页。

用户已明确选择保留最新个人页与转盘。旧 3.0 工程不再作为这次体验版的发布基线。

## 记忆瓶入口

- 时光页的「记忆瓶」卡片。
- 我的页的「记忆瓶」菜单。
- 一条现有日记对应一颗按心情着色的小球，点击打开原日记。
- 60 条以上通过上一瓶/下一瓶完整分页；返回后重读编辑或删除的记录。

## 动画修复

- 移除 28ms 主动限帧，跟随屏幕 requestAnimationFrame 绘制。
- 瓶身与玻璃边缘缓存为离屏图层，表情按颜色和心情缓存到图集。
- 像素预算限制在 2x；不支持离屏绘图时保留矢量降级。
- 预计算瓶壁法向量，只对实际相交的圆求平方根，并按帧间隔减少物理子步。
- 保留传感器晚到、页面隐藏/返回和纹理重建时的清理与状态保护。

## 验证记录

专项测试 43 项通过，覆盖碰撞、颜色、分页、点击、生命周期、60/120Hz 绘制、
