# Pal 简单聊天与日记来信：已确认设计

日期：2026-10-29。用户确认 GPT-6 Luna、全站每月30元模型预算，耗尽暂停AI，普通互动继续。之后用户说明每月有100美元的 OpenAI API 平台赠金或组织额度；这不是提高消费上限的授权。

## 产品范围与已选方案

考虑过仅聊天、仅来信、聊天加来信与动作三种方案。用户选轻量组合并要求简化：本人小屋进入聊天；现有信箱请求日记短信。普通摸头、姿态、走动、签到、任务、家具、现有模板来信均不依赖AI。保留自定义名字和八个角色已有的人设，不为八个角色分别调用模型。

聊天：用户主动开启，3次/北京时间自然日；最多保留最近两轮，由服务端组装历史；每次输入最多160个Unicode字符，回复目标50-100字，程序上限120字。聊天不自动读取日记。
来信：2次/北京时间自然周（周一开始）；用户在信箱选用本人最新一篇云端日记，并逐次确认发送其最多600字的文字片段和心情给OpenAI。片段与心情逐字绑定本次确认，云端源发生变化则拒绝发送并要求重新确认；照片、地图坐标和好友日记不发送；不自动迁移本机日记。回复目标150-250字，上限280字；保留最近12封，用户可删除或停用并清空。普通模板来信继续单独显示。
不增加自动定时生成、通知推送、语音、识图、联网搜索、向量库、模型自动发奖或改存档。聊天与来信均只用一个模型，不自动升级到更贵模型。

## 技术与数据

沿用原生微信小程序TypeScript/WXML/WXSS与CloudBase；新增独立pal-ai云函数，不改动已部署companion-api。使用OpenAI官方Responses API，model固定gpt-6-luna，reasoning.effort=none，store=false，service_tier=default，不配置工具或后台任务。API Key只从云端环境变量读取，不进入客户端、Git或日志；缺少Key或运维开关时返回未开通，普通互动照常。
云函数每次从可信APPID/OPENID计算身份并核对users active状态，不相信客户端ownerId、历史、人设、额度或模型价格。角色ID走服务端白名单，自定义名字限16字。客户端不能读写预算集合。
私有AI状态放入本人users文档的palAI字段：同意状态/代次、最多两轮历史、最近12封信、有限幂等结果和在途锁。使用显式字段返回，不暴露users文档；现有账号删除移除users文档即可删除AI正文，禁止完成中的请求复活账号或已清空状态。AI功能另提供停用并清空入口，不改日记。
新增ADMINONLY集合pal_ai_budgets（月聚合）和pal_ai_requests（幂等及日/周计数）。后者仅存匿名哈希键、状态、额度、用量和时间，不保存聊天或日记正文，清空不重置限额或总预算。按SHA256生成文档ID，只用精确文档事务，不在事务内发外部请求。

## 预算与请求生命周期

30元是全站模型消费记账上限，不是每人上限，也不是OpenAI控制台告警。后台固定保守折算10元/USD，按输入$0.125/百万（含最大30分钟缓存写入费）、输出$0.50/百万计费；由此30元最多放行约$3的模型费用，给兑换费用留余量。这是运维预算折算，不承诺实际账单汇率。计价版本固定并可运维停用；不因100美元赠金提高上限。预算计算使用整数纳元人民币。
服务端预留单次输入上限4096 token及聊天192/来信384输出token的最坏费用，同时事务检查全站月余额、个人日/周计数和单人在途锁。每个请求必须有客户端随机requestId；同一用户相同ID只执行一次。未知结果由单独result只读接口查询，额度耗尽或开关关闭不阻挡既有结果读取；终态失败释放客户端挂起ID，下一次显式请求重新受限额检查。预算拒绝时不调用OpenAI。计费自然月、个人日/周均按Asia/Shanghai；跨月响应记入原预留月份。
外发前先进行微信内容安全检查；再用Responses input_tokens计数接口核对完整请求不超过4096（含结构化输出），超出或计数失败不生成。计数与生成前均再次核对同意代次和账号有效；以事务标记sent为外发边界，尚未进入sent的请求在停用/删除后停止。已进入sent的请求可能仍产生费用，但清空/删号后绝不回写或展示结果。生成只发一次，不做自动重试。
拿到可信usage后按保守费率结算并释放未使用预留；超时、连接中断、未知usage保留整笔预留，不猜测退款，不重新调用。输出不合格或内容检测失败仍记入已消耗费用，界面不显示伪成功。超过预留的异常usage触发AI全站暂停，供人工检查价格/协议；不开放新请求。过期在途锁可让新请求继续，但原预算不会释放，原响应不能覆盖新状态。
预算耗尽显示“本月AI额度已用完，普通互动照常”，下个北京时间自然月自动使用新月账本。失败仅显示安全错误码和通用提示，不回传密钥、上游错误原文或完整日记。
