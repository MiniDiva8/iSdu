# Pal 底部入口设计

用户要求：在现有四个底部入口新增Pal，方便一步进入家园。沿用之前已授权由我决定的实现细节。

底部顺序：日记 / 校园 / 时光 / Pal / 我的。四个原入口保持，Pal位于我的之前；使用同组原创线条图标。点击Pal直接打开当前 `/pages/companion/index` 家园。保留个人页等旧入口与小屋分包，以及刚修复的底部布局。

实现选择：保持原生tabBar，在主包新增轻量 `pages/pal/index` 入口；首次展示/用户点击Tab自动navigateTo现有分包家园。相比重写自定义TabBar或迁移/复制小屋Canvas页面，此方式改动更小、原有共享链接及生命周期保持。返回后显示简洁Pal入口卡，可选择其他Tab或再次进入，不自动弹回；加载失败有重试。

原生Tab事件可能在onShow之前或之后到达，按可见性、待处理跳转和家园打开状态去重；隐藏/卸载后的旧回调不改页面。入口不读写宠物存档、奖励、余额或好友状态，不接受外部owner查询参数。

本轮仅本地实现与验证，不提交、推送、云部署、上传手机预览或替换体验版。
