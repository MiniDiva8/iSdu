# 日记贴纸创作设计

日期：2026-10-29。需求：借鉴用户提供的喜茶定制喜贴交互，完成 iSdu 写日记时自主创作贴纸的设计和接入。用户将设计与实施交由本轮完成，以下产品取舍由实施者确定。

## 调研与使用目标

- 用户四张截图直接展示：空白画布、画笔/橡皮擦和笔宽、文字短句、分类素材、撤销/重做、提交创作。截图只作交互参考，不复制喜茶品牌、插画或文案。
- 喜茶报送案例：https://m.adquan.com/case2/detail-363547 （2026-09-29）；喜茶 GO 开发者应用介绍：https://r.app.xiaomi.com/details?id=com.heyteago 。2026-10-29 搜索结果说明 DIY 手绘与个性化杯贴；未登录其小程序进行完整实测。
- 使用目标：不会画画也能通过素材和文字完成一张属于今天的贴纸；可仅用贴纸写日记，也可与照片、文字一起记录。

## 方案与取舍

1. 仅提供固定表情：接入轻，但不能满足自主创作，排除。
2. 原生 Canvas 创作并导出 PNG，接入现有图片链路：本轮采用。保留草稿可编辑；成品兼容日历、地图、详情、相册、云端及原可见范围，不扩张服务端数据权限。
3. 云端保存完整可编辑图层、跨设备素材库：涉及新模型、存储和部署，不属于本轮必要内容。

## 交互

- 编辑页的照片旁新增显眼的「创作贴纸」，重进创作页恢复「上次创作」的单份草稿，不暗示任意历史 PNG 可还原图层。贴纸与照片合计沿用三张上限，满额时明确提示先移除一张。
- 独立普通分包创作页：奶油纸与绿色控制条，与现有日记一致；方形画布、底部工具区、安全区。
- 画笔：颜色、粗细；橡皮擦只擦涂鸦；文字：自定义内容与日记短句；素材：原创简笔画的日常、校园、自然分类。
- 选择：点击选中文字/素材，可拖动、缩放、旋转、删除；绘制工具与选择工具明确区分。撤销/重做覆盖一次完整笔画或一次对象变更。
- 背景支持纸色与透明。空白作品不能加入。导出高分辨率 PNG；画布选择框和提示不进入成品。
- 「加入日记」通过事件通道把临时 PNG 返回原编辑页；仅此按钮改变日记图片选择，返回或中断不插入空白图。
- 本机保留最近一份创作草稿。离开、切后台、导出失败可恢复。明确说明草稿只在本机；旧文字草稿逻辑保持。加入日记后的编辑不修改已保存日记中的原图，需重新加入/替换。
- 云模式仅在保存日记时按原照片链路上传成品，编辑草稿不上传，不额外调用 AI。

## 验收

1. 绘制、橡皮擦、文字、分类素材、移动/缩放/旋转/删除、撤销/重做均实际改变文档和输出。
2. 空白拒绝、Canvas 不可用提示/重试、导出失败保留内容、重复加入/晚到回调受保护。
3. 从日记返回的作品与原有照片并存，贴纸独立日记能够保存并重开；满额、保存中、卸载后不接收作品。
4. 草稿恢复、损坏数据、存储失败、清除本机数据覆盖。
5. 新增逻辑与页面流程测试、全工程检查、官方 WXML/WXSS 编译、三种手机宽度的实际模板与实际绘制器浏览器检查。原生运行或真机没有执行时明确记录。
6. 同步 registry、交接说明及机器证据；本轮不上传、部署、提交 Git 或正式发布。
