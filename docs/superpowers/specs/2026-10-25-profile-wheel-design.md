# 个人主页与选择转盘设计

用户已提供两张界面参考，明确要求完成修改后上传体验版；沿用本会话直接实施的授权。

## 界面

个人主页采用浅色方格纸、手绘圆形头像、姓名和三项统计（日记数、字数、连续天数）、两张并列入口卡、浅黄色校园入口和灰米色分组设置。卡片连接现有日记、好友、照片、资料、备份等功能；默认心情/默认主题可设置，统计面板显示真实日记数据。主题指当前产品已有的日记分类（校园生活、学习、友情等）。

心情和主题共用全屏原生选择页。12 种现有心情与 9 种现有主题沿圆周排布，图形始终朝上；中心提示当前选择，右侧选中位，拖动转动、松手吸附、短惯性、轻点选择、箭头确认、底部 X 取消。选中不立即写入日记。尊重小屏、微信胶囊和安全区；完整转盘不会受原生 TabBar 或编辑区遮挡。

## 实施选择

采用独立原生页面承载转盘，复用现有 CSS 表情与 TDesign 图标；编辑页通过 EventChannel 接收确认结果，新建入口确认后 redirectTo 编辑页。相比覆盖层可避开原生 TabBar/textarea 层级；相比 canvas 保持文字可访问性与原生事件测试能力。其余备选没有额外收益。

## 数据

保持既有心情/分类枚举、日期与云端协议。已有记录不套用新默认值；默认值只用于新建，取消选择不覆盖字段。偏好仅存本机，不包含正文/照片；清除全部本机数据包含偏好。统计剔除示例记录，字数按非空白 Unicode 码点计，连续天数截至今天或昨天；日期统一北京时间。

## 验收

角度跨 ±180 度连续、12/9 项索引和吸附正确、中心死区/多指/滑后误触处理、取消/返回无记录写入、编辑图片文字和权限保留、未来日期拒绝、统计去重/跨年、偏好恢复与清理。
