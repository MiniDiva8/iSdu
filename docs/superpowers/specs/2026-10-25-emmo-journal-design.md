# iSdu 日记界面与校园功能整合设计

日期：2026-10-25。用户明确要求直接实施，本轮不增加确认环节。

## 目标与范围
在现有 iSdu 上实现 EMMO 式月份表情墙、心情选择、纸张日记编辑、详情、列表和照片回顾，并接回校园插画地图、好友邀请、可见范围和点赞。
交付原生微信小程序源码、可核验的自动检查和预览材料。保留 iSdu 品牌及校园核心，不实现 EMMO 的商店、会员、Pal、公开广场或私信。
依据 Android 3.1.2 静态拆解中的页面组织与控件尺寸独立重写；不复制反编译 Java 或许可证不明的商业图片。

## 技术与隔离
TypeScript、WXML/WXSS、TDesign MiniProgram 1.15.3、CloudBase。
开发副本位于原项目的 .worktrees/emmo-journal；原交付文件不覆盖。
当前源副本无 Git 元数据，因此新开发副本保存导入基线；不声称恢复了旧仓库历史。

## 界面
- 日记：五列表情墙、年月切换、搜索、照片入口、心情选择和新日记入口。
- 编辑：心情、日期、正文、最多 3 张照片、可选校园地点；分类和云端分享放入可展开选项。
- 回顾：保留既有我的/好友时光，增加月份照片墙。
- 校园：保留可拖动缩放的插画地图、聚合与好友图层。
- 我的：保留个人资料、统计、云端启用、数据管理与好友入口。
表情组件使用本项目原创 CSS 图形。默认配色为纸白、浅黄和墨色，地图保持既有底图。

## 数据兼容
沿用 Memory 和现有 Repository 接口，不要求变更现有云函数部署。
无地图位置的日记使用保留版本标识 journal-unlocated-v1；兼容字段 x/y 固定为 0，它们不是校园点位。地图与跳转入口必须识别该标识，绝不在角落画虚假标记。
所有旧记录、坐标版本、好友权限与迁移规则保持兼容。日记日期统一按北京时间分组；历史日期使用当天中午，今天保留实际记录时间。
本机新日记支持文字、心情和地点草稿；草稿不进入好友分享，云端模式不读取本机草稿。临时照片不会被宣称为已持久保存的草稿。

## 接口
- utils/journal.ts：JOURNAL_UNLOCATED_MAP_VERSION、getJournalDayKey、shiftJournalMonth、createJournalTimestamp、hasJournalLocation、buildJournalMonth。
- services/journal-draft-service.ts：本机文字草稿 read/save/clear，校验存储版本和字段。
- pages/journal：只从 active memoryRepository 读本人记录；不在本地模式访问云函数。
- pages/location-picker：用现有校园底图和比例坐标纯函数选点，通过 EventChannel 返回，不启用 GPS。
- 既有 editor/detail/timeline/map/profile/friends：复用业务服务，只补必要入口与位置判断。

## 验收
1. 能从日记首页创建、保存、查看、编辑和删除文字/照片日记；重启读取已保存记录。
2. 月份切换、跨年、闰年、同日多条和北京时间跨日分组正确。
3. 无地点日记不进入校园地图；选点后详情、时间轴和校园图定位一致。
4. 既有好友邀请、三档权限和点赞沿用受控云函数，本机模式不伪造好友成功。
5. 原项目检查及新增业务测试通过；检查 WXML/WXSS、类型、格式、安全扫描。
6. 原生开发者工具/真机如无法连接，明确列为未验证，不把浏览器预览当作真机验收。
