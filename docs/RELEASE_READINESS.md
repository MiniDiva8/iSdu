# iSdu Social V2 发布准备与门禁

更新日期：2026-08-15

## 当前结论

比赛第一版已保留，可独立恢复。Social V2 的本地代码、云函数、自动测试和安全文档已经进入收尾，但真实 CloudBase 环境尚未由用户创建，双微信账号、iOS 和 Android 真机安全矩阵尚未执行。

当前唯一允许的状态表述是：

> 代码与自动测试完成，真实社交安全待验收。

不得宣称已经正式上线、云端安全已经真机通过或所有设备兼容。

## 发布前硬门禁

- [ ] 已保留比赛第一版标签与提交，没有覆盖或重写历史。
- [ ] 已使用真实小程序 AppID 创建独立 CloudBase 测试环境；AppID、环境 ID、OpenID 和密钥未进入 Git。
- [ ] 已按 `CLOUDBASE_SECURITY_DEPLOYMENT.md` 创建 8 个集合、唯一索引、仅管理端数据库权限和私有云存储规则。
- [ ] `auth-api`、`memory-api`、`friend-api` 已从当前提交重新部署。
- [ ] 已执行 `npm.cmd ci` 与 `npm.cmd run check`，包括敏感信息、大文件和云函数依赖扫描。
- [ ] 已按 `SOCIAL_V2_MANUAL_TEST.md` 用两个微信账号、iOS 和 Android 完成越权与弱网验收。
- [ ] 微信公众平台隐私保护指引已按 `PRIVACY_GUIDE_DRAFT.md` 更新并由真实运营主体核对。
- [ ] 名称、服务类目、校园地图与照片素材具有可证明的使用依据；未获授权时不使用校徽或宣称官方。
- [ ] 开发者工具重新“构建 npm”，主包大小、代码质量与控制台异常均已人工检查。
- [ ] 已清除测试邀请、测试好友、测试图片、不适合审核的回忆和故意损坏的数据。

## 回归重点

1. 未开启云功能的老用户仍能完整使用本地版。
2. 迁移默认私密，部分失败不切换云端主数据。
3. 好友必须双向主动确认，不读取微信好友列表。
4. 删除好友、改私密和关系重建后旧授权立即失效。
5. 点赞幂等，越权请求失败，客户端看不到点赞名单。
6. 好友 24 小时地图只返回有权限的最小点数据。
7. 图片 fileID 不暴露，短期地址必须先鉴权。
8. 删除云端账号不误删本机副本，异常不静默成功。

## 上传与回退

验收通过后，从冻结的候选提交生成体验版。上传备注必须准确说明云端备份、iSdu 好友、可见范围和点赞能力。审核期间不要继续修改同一个候选版本。

若 Social V2 出现阻断问题，切回已保留的比赛第一版提交/标签；不要使用 `git reset --hard` 覆盖历史，也不要删除用户的本机数据。CloudBase 数据结构变更必须先在测试环境验证，再单独制定生产迁移和回滚方案。
