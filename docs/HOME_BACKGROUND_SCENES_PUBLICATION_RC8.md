# 首页背景、原图场景与小屋开放状态（rc8）

本轮根据 rc7 真机反馈完成三处修复；延续全面优化、时光地点/心情标题、伙伴游乐场、独立主题与一排分享范围。发布结果以匹配的体验版交付记录为准。

## 首页个性背景

开启个性背景后移除整块 94% 不透明的米白衬底和默认纹理，照片铺满首页。只在日期、文字和操作按钮周围保留小范围可读性衬色；每日圆点、心情表情和原点击区域保留。未来日期仍不可编辑，但日期文字保持可读。

10–100% 清晰度滑杆、仅本机存图、更换/失败重试、恢复默认和本地清除能力保留。滑杆只改变图片透明度；100% 不附加整页米白遮挡。弹层、日记详情、搜索结果与默认背景仍使用原有阅读样式。

## 好友开放状态

“好友来做客”卡片内展示检查中、正在开放/关闭、已开放、已关闭、未能确认；错误提示直接跟在状态下方。“重新核对开放状态”只读取服务端，不再次发布小屋。

只有已确认开放才提供关闭、同步及分享入口。网络失败或回复丢失后不能把旧的“未开放”当作当前事实，先显示未能确认；查询成功后恢复准确状态。服务端成功、本机标记保存失败时仍保留服务端已确认结果，并显示本机保存提醒。旧查询、隐藏页面回调不能覆盖更新后的状态。发布回执还必须确认请求的可见范围。

当前登记未记录 companion-api 部署；本轮不把客户端体验上传当作云服务开通。服务不可达/未开通时给出明确失败提示，不伪造已开放。双账号好友访问与真机验收仍需在真实云服务可用后执行。
