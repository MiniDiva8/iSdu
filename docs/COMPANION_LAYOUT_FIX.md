# 小屋底部文字重叠修复

2026-10-26，当前源码 3.2.0-rc.3。

## 原因与修改

操作提示原先按屏幕高度的17%固定定位，伙伴卡、动作按钮和底部手势提示分别按rpx及安全区定位；它们不参与彼此排版，因此领取提示会盖住伙伴名称，按钮换行和来访留言也可能互相覆盖。

首页增加统一的 `home-footer` 纵向布局。提示、引导、伙伴卡、动作、编辑/留言栏和手势说明依内容高度排列，保留12rpx间距，统一预留底部安全区与右侧相机控件的位置。伙伴名称保持单行省略，头像及操作按钮不被文字挤压。

本轮运行源码仅修改 `miniprogram/pages/companion/index.wxml` 和 `index.wxss`；余额、库存、存档、业务逻辑、资源与其他页面均与本轮基线一致。
