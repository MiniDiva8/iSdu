# 时光页背景封面

## 使用

在微信开发者工具打开本项目，进入底部“时光”页，点击顶部封面或右上角“设置封面”。选择“选择一张封面图片”，从相册或相机选择一张图片，保存成功后会显示“封面已更新”。再次点击封面即可更换，或选择“恢复默认封面”。

- 支持一张不超过 10 MiB 的压缩图片，按封面区域等比填充，边缘可能被裁切。
- 封面保存在当前设备的小程序用户文件目录；重新进入、切换时光范围后仍保留。封面不随云端回忆同步，换设备需要重新设置。
- 取消选择不改变封面；保存失败保留旧封面。图片失效时显示默认背景，可直接重新选择。
- “我的空间 → 数据管理 → 清除全部本机数据”会一并清除封面；仅删除某条回忆不会删除封面。
- 未部署或发布云端内容。本功能不新增云函数或数据集合。

## 实现位置

- `miniprogram/pages/timeline/index.{ts,wxml,wxss,json}`：顶部封面、原生图片选择、失败与恢复交互。
- `miniprogram/services/timeline-cover-service.ts`：独立设置、永久图片保存、替换回滚和目录清理。
- `miniprogram/pages/data-management/index.ts`：接入已有本机数据清理流程。
- `miniprogram/services/timeline-cover-service.test.mjs` 与 `scripts/timeline-cover-flows.test.mjs`：保存与页面流程回归测试。
