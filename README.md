# 校迹拾光 iSdu

用心情日记记录校园生活，把照片和回忆留在校园地图上，再与拾光伙伴一起回顾。

当前源码版本为 **3.2.0-rc.10**，整理日期为 **2026-10-30**。本仓库保存当前日记与 Pal 主线的源码、测试、运行素材和交接文档。历史版本、设计原图和比赛材料通过[资料索引](docs/PROJECT_MATERIALS.md)定位。

[当前整合状态](docs/CURRENT_LOCAL_INTEGRATION.md) · [本次 GitHub 同步](docs/GITHUB_SYNC_20261030.md) · [开发交接](docs/AI_HANDOFF.md) · [第三方声明](docs/THIRD_PARTY_NOTICES.md)

## 当前功能

- **心情日记**：月份心情墙、文字与照片、日期补记、校园地点、搜索、本机文字草稿与自定义首页背景。
- **贴纸创作**：涂鸦、橡皮、文字、12 类原创素材、拖动与双指变换、撤销重做和本机草稿；导出 PNG 后与照片合计最多三张。
- **校园与时光**：二维插画地图、比例坐标记忆点、月份时间轴、照片墙、本机封面与记忆瓶。
- **个人主页**：日记统计、心情与主题转盘、偏好设置和动态头像。
- **好友分享**：主动邀请建立双向好友、仅自己/指定好友/全部好友三档权限、点赞和近 24 小时好友地图。
- **Pal 拾光伙伴**：8 位校园角色、小屋与场景、22 件正式家具及 2 件旧收藏、任务与奖励、收藏、合影、来信和游乐场。
- **Pal AI**：保留聊天与日记来信实现；最近部署记录显示连接超时，AI 保持暂停。普通伙伴互动和模板来信继续可用。

底部导航为：**日记 / 校园 / 时光 / Pal / 我的**。旧公开圈子没有并入当前日记主线。

## 运行与检查

需要 Node.js `^22.15.0 || >=24`、npm `>=10` 和微信开发者工具。

```powershell
npm.cmd ci
npm.cmd run check
```

在微信开发者工具导入本仓库根目录，按需执行“工具 → 构建 npm”。公共配置使用 `touristappid`，可体验本机日记；在线好友、云端照片及伙伴服务需要自行配置微信身份和 CloudBase。真实 AppID、环境 ID、令牌和私有配置不进入 Git。开发者工具生成的依赖目录也不进入 Git。

本机已有项目导航时，先执行导航根的 `tools/project-context.mjs context`，再使用输出的真实源码目录运行工程命令。独立 clone 的开发者直接使用仓库根目录即可。
