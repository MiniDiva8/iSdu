# 静态资源目录

当前只包含一张用户提供并清理标注后的校园地图候选图：

- `demo/campus-map-placeholder.jpg`
- `1448 × 1086`
- 490,518 字节（约 479 KiB）
- 由用户提供的 `2.49 MiB` PNG 转为 JPEG 质量 90，保持原始像素尺寸
- 用于地图拖动、缩放、比例选点与本地回忆闭环验证

仓库没有内置 Demo 照片、第三方字体或图标。用户选择的照片运行时保存到 `USER_DATA_PATH`，不会进入本目录。

当前地图的生成过程、PNG 源文件和比赛使用权仍需在正式参赛前归档。后续资源必须原创或具有可证明的使用授权；替换或裁切地图前还必须制定已有比例坐标迁移方案。
